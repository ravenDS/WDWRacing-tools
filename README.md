# WDWRacing-tools
A collection of tools & Blender plugins for **Walt Disney World Quest: Magical Racing Tour** (PC/PS1)

### Currently supports: 
- Import of WDWR PC (**.DFX**) & PS1 (**.DRM**) level files
- Textures extraction from associated files (**.VD3** & **.VRM**)
- Level Geometry
- Objects Geometry
- Characters & Cars Geometry
- Objects placement
- AI paths & animation paths
- Track overlay & checkpoint placement _(experimental)_

### Work-in-progress: 
- Animation data
- Proper animation paths for specific objects
- Track FX & overlay processing
- Dreamcast format
